
# 🍎 Personal Calorie Calculator

## ✨ Project Introduction

This project is a simple Python program that calculates the Basal Metabolic Rate (BMR) based on user's personal information and sets a personalized daily calorie target according to activity level and weight goals. 📊 It helps users manage their healthy eating habits by indicating whether their calorie intake exceeds or falls short of their target. 

## 🚀 Key Features

*   **User Information Input**: Collects age, gender, height, weight, and activity level. 👤
*   **Basal Metabolic Rate (BMR) Calculation**: Calculates BMR using the Mifflin-St Jeor equation. 💡
*   **Target Calorie Setting**: Suggests daily calorie targets for weight loss, maintenance, or gain. 💪
*   **Calorie Intake Input**: Users input their estimated daily calorie intake. 🍽️
*   **Result Comparison**: Compares target calories with actual intake and displays the result. ✅

## 🛠️ How to Use

1.  **Run the Code**: Execute `calorie_calculator.py` (or the relevant code cells) in a Jupyter Notebook, Google Colab, or a Python environment.
2.  **Enter Information**: Follow the prompts to enter your age, gender, height, weight, activity level, weight goal, and daily calorie intake. ⌨️
3.  **Check Results**: Once input is complete, you can view your calculated BMR, target calories, and whether your intake is over or under your goal. 📈

## 💡 Constraints and Notes

*   **Focus on Basic Calculation**: Emphasizes core calorie calculation rather than complex nutritional analysis.
*   **Offline Usability**: Can be used without an internet connection. 🌐
*   **Simple and Intuitive UI**: Provides a terminal-based, user-friendly interface.
*   **Mobile Compatible**: Can be used on mobile devices via Python-compatible apps.
*   **Estimates Only**: All calculations are estimates. For precise medical or nutritional advice, please consult a professional. 👩‍⚕️👨‍⚕️

## 🌟 Core Goal

**"User Information Input ➡️ Calorie Calculation ➡️ Result Comparison"**

The goal is to help users understand and manage their calorie intake through this simple flow.
